# FullStack Open Projects

Collection of projects and exercises developed while completing the Full Stack Open program by the University of Helsinki.

This repository includes frontend and backend applications focused on modern fullstack web development using React, Node.js, MongoDB, GraphQL, Redux, and TypeScript.

## Technologies Used

- React
- Redux
- Node.js
- Express.js
- MongoDB
- GraphQL
- TypeScript
- REST APIs
- JavaScript
- Testing

## Topics Covered

- Frontend and backend integration
- RESTful API development
- State management with Redux
- Database integration with MongoDB
- GraphQL queries and mutations
- User authentication
- Testing fundamentals
- Fullstack application architecture
